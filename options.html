General

⚠ Inline mode writes the original values into the page, where the chat site's own scripts (analytics, session replay, "share" features…) can read them. Use hover mode unless you trust the site.

Placeholders only resolve on the site where they were created: a placeholder from claude.ai is never shown on another site. The compose area always shows exactly what will be sent.

Each rule can define its own replacement text, which takes precedence over this mode. Restoring only works with consistent placeholders: masks and asterisks cannot be undone. Placeholder mappings are kept in memory only and are cleared when the browser closes.

Memory

Your own keywords: people, companies, clients, projects… They are always obfuscated (ignoring case, accents and spacing) and each category gets its own placeholder: [PERSON_1], [CLIENT_1]… By default a term matches as a whole word (hooli in HOOLI_DC or hooli.local); with Partial match it also matches inside other words (HooliDC → [CORP_1]DC). Memory is stored only in this browser, never in the repository. You can also select text on any site and right-click → Add to Trellis memory, or use the toolbar popup.

Rules

Keywords: separated by commas or new lines, ignoring case and accents. Regex: JavaScript syntax; default flags gi (remove the i to make it case-sensitive). When two rules match the same text, the longest match wins.
